# Миграции PostgreSQL

`00001_init.sql` фиксирует начальную версию без изменений схемы. Когда согласуем схему, добавим следующую миграцию с номером `00002`. В каждом файле секция `-- +goose Up` применяет изменения, а секция `-- +goose Down` описывает откат. По умолчанию Goose выполняет каждую миграцию в отдельной транзакции.

`docker compose up --build --wait` применяет новые миграции перед запуском API. Результат можно посмотреть командой `docker compose logs migrate`.
