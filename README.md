# УДАВ — бэкенд

Бэкенд на Go для мобильной и браузерной версий УДАВа. В игре два соперника трясут телефоны и соревнуются, кто первым заполнит шкалу.

## Основные команды

Выполняйте из корня проекта.

| Действие | Команда |
| --- | --- |
| Собрать и запустить API, PostgreSQL и S3 | `docker compose up --build --wait` |
| Посмотреть статус контейнеров | `docker compose ps` |
| Следить за логами API | `docker compose logs -f api` |
| Остановить контейнеры | `docker compose down` |
